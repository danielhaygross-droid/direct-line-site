2 · Export orders to Excel

PR #86 → #87 · live

Shahar: a client wants to export their orders to see the prices and mark which ones have been paid. It went out first as Word (#86). You preferred Excel, so #87 replaced the Word export.

  • Client portal › Orders: an Export to Excel button. It exports the orders on screen, following the store, status, search and sort.
  • Admin › client panel › Orders: the same button, for that client.
  • The file: Order · Date · Customer · Product · Qty · Status · Total · Paid (a Yes / No drop-down, green when Yes). Under the table: Total, Paid and Not paid yet, which update by themselves.
  • Orders without a price show "Not priced yet" and cancelled orders show "Cancelled"; neither is counted. Each header has a filter button, the header row stays visible, and the sheet prints landscape. Hebrew: right-to-left, with Paid = כן / לא.

Checked: unit tests read the file back (valid ZIP, rows, numbers, formulas, drop-down, filter, right-to-left). A screen check downloads it from the portal (also filtered) and from admin, in EN/HE at 1440 and 390 px. The files were opened in Excel: no repair prompt, and marking an order Yes moved its total from "Not paid yet" to "Paid". The Word version (#86) had also been opened in Word before it was replaced.
